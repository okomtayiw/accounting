Kebijakan Privasi

Terakhir diperbarui: [ISI TANGGAL, contoh: 18 Jan 2026]

Kebijakan Privasi ini menjelaskan bagaimana aplikasi accounting-system (“Aplikasi”) mengumpulkan, menggunakan, menyimpan, dan melindungi data pengguna. Dengan menggunakan Aplikasi, Anda menyetujui praktik yang dijelaskan di bawah ini.

1. Data yang Dikumpulkan

Aplikasi dapat memproses beberapa jenis data berikut (tergantung fitur yang Anda gunakan):

  • Data transaksi: pemasukan, pengeluaran, kategori, catatan, tanggal, dan informasi laporan harian.
  • Data perangkat (opsional): informasi teknis dasar seperti tipe perangkat/versi sistem untuk stabilitas aplikasi.
  • Data akun (jika ada): nama, email, atau informasi login yang Anda masukkan.
  • Analitik (jika diaktifkan): data penggunaan untuk peningkatan performa dan pengalaman pengguna.

2. Cara Data Digunakan

Data digunakan untuk:

  • Menyediakan fitur pencatatan pemasukan/pengeluaran dan pembuatan daily report.
  • Meningkatkan kualitas layanan, memperbaiki bug, dan menjaga keamanan.
  • (Opsional) Mengirim informasi penting terkait layanan jika Anda menghubungi kami.

3. Penyimpanan Data

Secara default, data Anda disimpan:

  • Lokal di perangkat (contoh: database lokal) jika Aplikasi berjalan offline.
  • Di server (jika Aplikasi memakai sinkronisasi/login) untuk menyimpan dan menyinkronkan data.

Catatan: Sesuaikan bagian ini sesuai kondisi aplikasi kamu (lokal saja atau ada server).

4. Berbagi Data dengan Pihak Ketiga

Kami tidak menjual data pribadi Anda. Data hanya dapat dibagikan dengan pihak ketiga jika diperlukan untuk:

  • Layanan analitik/crash reporting (jika digunakan).
  • Kepatuhan hukum (jika diwajibkan oleh peraturan).

5. Keamanan

Kami menerapkan langkah-langkah yang wajar untuk melindungi data dari akses tidak sah, perubahan, pengungkapan, atau perusakan. Namun, tidak ada metode transmisi atau penyimpanan elektronik yang 100% aman.

6. Hak Pengguna

Anda dapat:

  • Meminta penghapusan data (jika aplikasi menyimpan data di server).
  • Menghapus data lokal melalui pengaturan aplikasi/perangkat (jika penyimpanan lokal).

7. Privasi Anak

Aplikasi ini tidak ditujukan untuk anak-anak di bawah 13 tahun dan tidak dengan sengaja mengumpulkan data dari anak-anak.

8. Perubahan Kebijakan

Kami dapat memperbarui Kebijakan Privasi dari waktu ke waktu. Versi terbaru akan ditampilkan di halaman ini.
